# 关卡设计哲学（LEVEL_DESIGN.md）

本文件定义全项目关卡的统一设计原则。**所有关卡生成/手改都必须遵守**，
否则视为不符合交付标准。

---

## 一、核心节奏：三拍循环

每一段流程都遵循「**压力 → 释放 → 奖励**」的三拍结构：

| 拍 | 内容 | 玩家感受 |
|---|---|---|
| 压力 | 遭遇敌人、狭窄走廊、Boss 房 | 紧张、需要操作 |
| 释放 | 清空房间、开阔安全区、存档点 | 松一口气 |
| 奖励 | 宝箱、词条三选一、回城 | 有回报、想继续 |

**不允许**出现"连续三场战斗中间没有任何释放"的段落——那是疲劳源。

---

## 二、关卡结构模板（每关都一样）

```
[入口] → 教学/引导房 → 主战斗房 ×2~3 → 岔路宝箱 → 存档点 → 关底门 → [下一层]
```

固定要素：

1. **入口房**：刚进场必须安全 3 秒内不被打。第一眼要能看到"往哪走"。
2. **主战斗房**：房间-走廊式布局，门是天然的节奏断点。
3. **岔路宝箱**：主路径之外必有 1 个宝箱，奖励"探索"而非"直线冲"。
4. **存档点**：每关至少 1 个，在关底门之前。死了不用从头再来。
5. **关底门**：需要**清光本关所有敌人**才开（锁门），或需要钥匙。

---

## 三、房间尺寸与视野约束

- 基准分辨率 320×180，视口一次看到 **20×11 个格子**。
- **战斗房**：宽 11~14 格、高 8~10 格 —— 略大于一屏，让玩家有"走位空间"
  但不会迷失。
- **走廊**：宽 2~3 格。够两个人并排，但不给闪避空间，制造压迫感。
- **不允许**单格宽的走廊（玩家会卡住）。
- **Boss 房**：宽 24~30 格、高 18~22 格，必须能容纳一次冲锋的直线距离。

---

## 四、敌人布置原则

| 原则 | 说明 |
|---|---|
| 距离 | 出生点 **≥ 5 格**内不放敌人 |
| 数量 | 单房间同时在场 **≤ 5 只**，避免视觉噪音 |
| 配比 | 近战 : 远程 ≈ 2 : 1；精英单独放，不和普通怪挤一起 |
| 视线 | 敌人不要正对门口，给玩家"进门先观察"的一拍 |
| 递进 | 第 1 层只出近战；第 2 层加远程；第 3 层加精英 |

---

## 五、视觉与可读性

- **墙必须可无缝平铺**（已用脚本逐块验证，见 `docs/ASSETS.md`）。
- **地板与墙对比度足够**，玩家一眼分清"能走"和"不能走"。
- **门/楼梯用显眼的地标**（不同瓦片或 Marker 视觉），不要藏在角落。
- **宝箱、存档点必须有独立外观**，不能和场景装饰混在一起。

---

## 六、难度曲线（全局）

```
城镇（0 战斗）
  ↓
野外（近战，教走位）        ← 简单
  ↓
地牢一层（近战+远程，教翻滚）  ← 中等
  ↓
地牢二层（加精英，教取消后摇）  ← 较难
  ↓
Boss 前厅（精英 + 存档点）     ← 最难前奏
  ↓
Boss 房（单体高伤，教观察）    ← 高潮
  ↓
回城（释放 + 结算）           ← 收尾
```

- 敌人**血量/伤害按层递增**，但**玩家的词条成长要能跟上**。
- 每层清怪给词条三选一，这是玩家变强的主要来源。

---

## 七、交互物规范

| 交互物 | 行为 | 设计意图 |
|---|---|---|
| 宝箱 | 打开得金币/药水 | 奖励探索 |
| 存档点 | 恢复满血 + 记录复活点 | 降低挫败 |
| 治愈泉 | 单次恢复 50% 血 | 中途补给 |
| 提示牌 | 显示操作/剧情提示 | 无 UI 打扰的引导 |
| NPC | 对话（城镇） | 世界观 + 教学 |
| 锁门 | 清怪/钥匙才开 | 控制节奏 |

---

## 八、检查清单（每个新关卡都要过）

- [ ] 入口 5 格内无敌人
- [ ] 至少 1 个宝箱
- [ ] 关底门前至少 1 个存档点
- [ ] 走廊宽度 ≥ 2 格
- [ ] 战斗房不超一屏半
- [ ] 有明确的下一个目标指示
- [ ] 死亡后不需要重玩超过 1 个房间
