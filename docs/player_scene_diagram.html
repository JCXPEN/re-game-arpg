玩家节点在场景树里的位置 & 它占用的碰撞层

左：场景树（Boot 容器 / 关卡 / 玩家挂载点）  |  右：project.godot 的 10 个 2D 物理碰撞层，金色为玩家占用

场景树 SCENE TREE

├─autoloads · EventBus / UIRegistry / GameFlow / PauseManager …
└─Boot main_scene
├─World Node2D 换关只动它
└─Level_xxx 当前关卡实例
├─Player CharacterBody2D · layer2
├─Hurtbox Area2D · layer4
├─AttackBox Area2D · layer6 mask→layer5
├─Sprite / Combat / Camera2D …
├─Enemy layer3/5/7
├─Floor / Walls layer1
└─NPC / Chest layer10
├─GUI CanvasLayer · layer10 HUD / BossHealthBar
└─Menus CanvasLayer · layer30 对话/暂停/背包…
★ 玩家是"世界物体"：住在 World→关卡 里，随关卡换场重建；
不进 Boot 的常驻层（GUI/Menus），所以没自己的"玩家容器"。

金色 = 玩家占用（来自 player.tscn 的 collision_layer 位掩码）
layer2=2¹ · layer4=2³ · layer6=2⁵
结论：场景树的 3 个容器是「世界 vs 界面」的架构分界（World / GUI / Menus）， 玩家作为世界物体挂在 World→关卡→Player 之下，随关重建，无需独立容器； 而玩家的「独立身份」由碰撞层 2 / 4 / 6 定义（对应 PlayerBody / PlayerHurtbox / PlayerAttack）。 两套"层"各管一摊，互不等价。
